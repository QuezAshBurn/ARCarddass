# Knowledge Hub

This file records the product decision around the Blog/Knowledge Hub.

## Current decision

The public Blog is not a broad Knowledge Hub right now. It should be a focused Pricing Newsletter.

Reason: the broad category hub created too many public topics and made the page feel unfocused.

## Do not expose for now

Do not show public topic chips for:

- Market Analysis
- Card Spotlight
- Set Guide
- Collector Guide
- Discovery
- Auction Watch
- Version Guide
- Grading Guide
- History

## If the full hub returns later

Only bring back multi-category content if explicitly requested. If restored, market-sensitive articles must be evidence-backed and should not invent sale prices, asking prices, bids, watchers, or market movement.

## Production behavior

Supabase published posts are authoritative in production. Development seed content can be used locally, but production should not pretend seed articles are live market journalism.
